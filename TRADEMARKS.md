# The EverythingApp name and icon

The code is free to use under the AGPL (`LICENSE`). The name "EverythingApp" and the app's icon are not part of that
license: they tell people which builds come from this project.

- **Fine without asking:** saying your project is based on EverythingApp, linking here, writing about it, and running
  or sharing unchanged copies built from this repository.
- **Please use your own name and icon** for a changed copy you share or publish, in any app store or download site, so
  nobody mistakes it for this project's builds or comes here for its support.
- **Ask first** for anything else that would use the name or icon, by opening an issue.
