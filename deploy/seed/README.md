# Starter data

What every new hub gets the first time `seed` runs (the installer runs it once): example snippets, packing
checklist templates, the US states checklist and a monitor for the hub itself. Nothing in it is anyone's own:
notes, hosts and facts of your own go in the personal seed folder below.
Facts, rules, plan rules, food options, music notes, snippets and monitors of your own go in the personal seed folder, by default
`<data dir>/seed/` (or `EA_SEED_PERSONAL_DIR`), with the same file names; `seed` reads it after this one. The
app's own Memory, Monitors and Plan pages are the usual way to add them.
